# Pull Request Policy

- Treat this repository as an independently maintained fork.
- Open pull requests against `aryanprince/invoicely` (`origin`) and target its `main` branch.
- Never open a pull request against `legions-developer/invoicely` or another upstream repository unless the user explicitly requests that exact destination.
- Before creating a pull request, verify the destination repository and base branch explicitly.
- Format pull request titles using the Conventional Commits convention used by recent commits, such as `feat: add invoice CLI workflow`, `fix: correct invoice totals`, or `docs: update setup guidance`.
- Write pull request descriptions as concise bulleted lists that summarize the changes and relevant validation.
